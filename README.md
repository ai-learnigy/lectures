# AI აგენტების შექმნა და მართვა .NET-ში — ლექციები

STEP-ის AI მოდულის (24 ლექცია) ყველა ლექცია ერთ ადგილას: პრეზენტაცია, კონსპექტი, კლასის და საშინაო დავალება, მასალები.

**სტეკი:** .NET 10 · Microsoft.Extensions.AI · Microsoft Agent Framework · MCP · PostgreSQL + pgvector · EF Core 10
**პროექტი:** RestaurantApi (API კურსიდან) — მენიუ, კალათა, შეკვეთა, ჯავშანი; ყოველ ლექციაზე ემატება AI.

## ლექციაზე

1. გახსენი საიტი, შეიყვანე კოდი (ერთხელ), აირჩიე ლექცია → **▶ პრეზენტაცია**.
2. გადაიტანე პროექტორზე, დააჭირე `F`.
3. `P` — **კონსპექტი** ცალკე ფანჯარაში. ის სლაიდებს მიჰყვება; კონსპექტში „სლაიდი N“-ზე დაჭერა პრეზენტაციას იმ სლაიდზე გადაიყვანს.
4. ნავიგაცია ისრებით: `→` შემდეგი, `←` წინა.

სხვა კლავიშები: `O` ყველა სლაიდი · `A` სლაიდის ყველა ნაბიჯი · `Shift+→` შემდეგი სლაიდი. ასოები ქართულ განლაგებაზეც მუშაობს.

სტუდენტები კონსპექტს სახლში ქარდიდან ხსნიან: **📖 კონსპექტი** — ახსნა, რესურსები, დავალებები და ტესტი.

**🎓 ლექტორისთვის** — `L` პრეზენტაციაში ან ქარდზე ბმული. ცალკე კოდით იხსნება (სტუდენტები ვერ ხედავენ): გეგმა, მოსალოდნელი კითხვები, დავალებების ამოხსნები და შეფასება.

## ლექციის სტრუქტურა

ყველა ნაწილი სავალდებულოა — `deck.html`-ში ცხადი tag-ებით, რომლებსაც build სლაიდებად აქცევს:

| tag | სლაიდი | საიდან |
|---|---|---|
| `<lecture-review/>` | გამეორება — წინა ლექციის კითხვები | წინა ლექციის `lecture.json` → `review` |
| `<lecture-homework-review/>` | წინა საშინაოს განხილვა + ამოხსნა | წინა ლექციის `homework.md` |
| `<lecture-intro/>` | დღის თემა: რატომ გჭირდებათ, რას შეძლებთ | `lecture.json` → `why`, `outcomes` |
| `<lecture-classwork/>` | კლასში დავალება | `classwork.md` |
| `<lecture-check/>` | შევამოწმოთ — ამ ლექციის კითხვები | `lecture.json` → `review` |
| `<lecture-homework/>` | საშინაო (ამოხსნის გარეშე) | `homework.md` |

ერთი და იგივე კითხვები ლექციის ბოლოს „შევამოწმოთ“-ში ჩანს და შემდეგი ლექციის დასაწყისში „გამეორებაში“ — ერთხელ იწერება. build შეჩერდება, თუ ლექციას რომელიმე ნაწილი აკლია.

`classwork.md` / `homework.md`: `# სათაური`, ქვესათაური, მერე `## მოთხოვნები` (ან `## ნაბიჯები`), `## ✓ მზადაა, როცა`, `## ⭐ ბონუსი`, `## 💡 …` (მხოლოდ კონსპექტში), `## ამოხსნა` (მხოლოდ homework-ში; ჩანს შემდეგ ლექციაზე; სლაიდზე გამოსაჩენი კოდის ბლოკი მონიშნე სათაურის ბოლოს `!`-ით).

## ლექტორის კოდი

### ინგლისური ვერსია (`deck.en.json`)

თუ ლექციის საქაღალდეში არის `deck.en.json`, build აწყობს `index.en.html`-საც. პრეზენტაციაში **EN / KA** ღილაკი იმავე სლაიდზე გადადის. კონსპექტი და ლექტორის გვერდი მხოლოდ ქართულია.

```json
{
  "ქართული ფრაგმენტი": "English",
  "_slides": { "19": { "ნომერი": "number" } },
  "_html":   [["<span>ზუსტი HTML</span>", "<span>English HTML</span>"]]
}
```

ფრაგმენტი არის ტეგებს შორის ტექსტი (trim), `data-section` / `title` ატრიბუტი ან სკრიპტის `'სტრიქონი'`. თუ სლაიდზე ახალი ქართული ტექსტი დაემატა და თარგმანი აკლია, build ამას სიით აჩვენებს. `_slides` — თარგმანი ერთი სლაიდისთვის, როცა ერთი და იგივე სიტყვა კონტექსტის მიხედვით სხვანაირად ითარგმნება. `_html` — როცა სიტყვების რიგი ინგლისურად სხვაა.

### თემები

ყველა გვერდს აქვს ღია და მუქი თემა (🌙 / ☀️ ღილაკი, პრეზენტაციაში ასევე <kbd>T</kbd>). არჩევანი ბრაუზერში ინახება და ყველა გვერდზე ერთნაირია. ფერები: `engine/theme-light.css`, `engine/theme-dark.css` (პრეზენტაცია), `engine/page-theme.css` (კონსპექტი, ლექტორი, მთავარი გვერდი). ახალ სლაიდზე ფონისთვის `#fff`-ის ნაცვლად გამოიყენე `var(--card)`, რომ მუქ თემაშიც სწორად გამოჩნდეს.

### კონსპექტი (`study.html`)

კონსპექტი სტუდენტისთვისაა, ვინც ლექცია გააცდინა ან გამეორება უნდა. სლაიდების `<aside class="study">` ტექსტები **თავებად** ლაგდება `data-section`-ის მიხედვით. თავში არის „⚡ 5 წუთში“ (მთავარი აზრები და გზა გაცდენილისთვის), ბოლოში ტესტი და ყველა ```terms ბლოკიდან აწყობილი ლექსიკონი. lecture.json-ში (არააუცილებელი):

```json
"study": {
  "summary": ["მთავარი აზრი 1", "…"],
  "skip": ["დღის თემა"],
  "chapters": { "2 · როგორ მუშაობს": { "title": "როგორ მუშაობს LLM", "goal": "ახსნი, რა არის ტოკენი…" } }
}
```

`skip` — სექციები, რომლებიც მხოლოდ ლექციაზე დასწრებისთვისაა. „ნაწილი N …“ სათაურის ბლოკი თავის შესავლად ჩანს.

დრო მქონე ნაწილები ლექციის გეგმაში (timeline) და ტაიმერში ჩადის. ბლოკის ფერს emoji წყვეტს. დავალებების სრული ტექსტი, ამოხსნა, შემოწმების კითხვები და ტესტის პასუხები ავტომატურად ემატება. `lecture.json → "lecturer_quiz"` ქმნის ლექტორის ტესტს „✅ მზად ხარ?“, `"lecturer_explain": [{"task", "points"}]` კი „🎙️ ახსენი ხმამაღლა“ ამოცანებს. გვერდს სამი რეჟიმი აქვს: 📖 ისწავლე → 🎯 მოემზადე → 📋 ლექციაზე.

ლექტორის გვერდი (`lecturer.html`) ყოველთვის დაშიფრულია. კოდი: `.lecturer-code` ფაილი root-ში (ერთი ხაზი, git-ში არ შედის) ან `LECTURER_CODE` ცვლადი. ფაილის გარეშე ბილდი ლექტორის გვერდს არ ააწყობს. კოდის შესაცვლელად — შეცვალე ფაილი და გაუშვი ბილდი.
