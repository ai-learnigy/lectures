Two worlds

Regular code vs a language model

🙋 How is a C# method different from an LLM? Name 3 differences

⚙️C# code

  • Input: exact (dishId, date)
  • Rules we write them
  • One input → always the same result
  • Error = a bug we find and fix

🧠LLM

  • Input: any text
  • “Rules” are learned from text
  • One input → can differ result
  • Error = a convincing falsehood
Neither replaces the other: an LLM understands people, C# code executes exactly. Our job is to connect them

📏Context window

in one request input + output token maximum. Anything beyond it the model can't “see”

🙋 ChatGPT “remembers” the previous message. Does the model remember it?

🐟The model has no memory

🛑What it does

limits the answer tokens. Once reached, writing stops even mid-word

🛡️Why we need it

Cost and Time limit: the model won't “get carried away” into a 3000-token answer
