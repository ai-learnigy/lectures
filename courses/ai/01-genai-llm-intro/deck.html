### ჩვენთვის LLM = კიდევ ერთი HTTP API Backend დეველოპერისთვის LLM ჯადოსნური არაფერია: ის **გარე სერვისია**, რომელსაც HTTP მოთხოვნას ვუგზავნით — ისევე, როგორც ამინდის ან გადახდის API-ს. თითქმის ყველა პროვაიდერი ერთნაირ ფორმატს იყენებს (ე.წ. **OpenAI-compatible** API). ზემოთ — Gemini-ს OpenAI-compatible მისამართი; OpenAI-ზე, Groq-ზე ან ლოკალურ Ollama-ზე მოთხოვნა თითქმის იდენტურია. **Request:** - `model` — რომელ მოდელს ვეკითხებით - `messages` — შეტყობინებების სია, თითოს თავისი `role` აქვს (`user`, `assistant`, `system` — მე-2 ლექციაზე დეტალურად) - `temperature`, `max_tokens` — პარამეტრები, მე-3 ნაწილში **Response:** - `choices[0].message.content` — პასუხის ტექსტი - `finish_reason` — რატომ შეწყვიტა წერა (`stop` — თვითონ დაასრულა, `length` — ლიმიტს მიაღწია) - `usage` — რამდენი **ტოკენი** დაიხარჯა. სწორედ ამაში ვიხდით ფულს. ამ JSON-ს ხელით არ დავწერთ — C#-ში ამას .NET-ის ბიბლიოთეკა გააკეთებს — კოდს შემდეგ ლექციებზე ვწერთ. მაგრამ კარგია იცოდე, რა მიდის „კაპოტის ქვეშ“.
