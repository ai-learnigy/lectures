## 🎯 მიმოხილვა

ეს **თეორიული** ლექციაა, კოდს არ ვწერთ. ორი მიზანი გვაქვს. პირველი: სტუდენტმა დაინახოს მთელი მოდული — რას ააწყობს 24 ლექციაში და ვინ გახდება. მეორე: სწორად წარმოიდგინოს, როგორ მუშაობს მოდელი, რომ მე-2 ლექციიდან, როცა კოდს დაწერს, საფუძველზე კითხვები აღარ გაუჩნდეს.

პრეზენტაციას არ კითხულობ: ის აჩვენებს იმას, რასაც შენ ყვები. ყოველ ახალ ცნებამდე ჯერ კლასს ჰკითხე (🙋), მოუსმინე 2–3 პასუხს და მერე ახსენი.

2. მოდელი ტექსტს **ტოკენებად** კითხულობს. ტოკენი არის ფასის, ლიმიტისა და სიჩქარის ერთეული, და ქართული ტექსტი მეტ ტოკენს იკავებს.

5. პარამეტრს და მოდელს **ამოცანის** მიხედვით ვირჩევთ, ხარჯს კი წინასწარ ვითვლით.

## 1 · მოდული: რას ვაწყობთ და ვინ გავხდებით · 23 წთ · 1–10

### 📋 ლექციაზე

- აქამდე AI-ს **იყენებდნენ**, ახლა **ააწყობენ**
- მოდელი წყვეტს, C# კოდი აკეთებს (SearchMenu, BookTable)
- „ვინ გახდებით“: AI Engineer, Agent Developer, Backend + AI
- 🙋 „სად გამოგიყენებიათ AI? რა ვერ გააკეთა?“
- 💡 ბანკის ჩატბოტი PDF-ებიდან → RAG, ლექცია 9–12

### 🎯 მთავარი სათქმელი

აქამდე AI-ს **იყენებდნენ**, ახლა **ააწყობენ**. მოდულის ბოლოს მათ API-ში იქნება აგენტი, რომელიც ადამიანის ენას იგებს და **მათი C# კოდით** მოქმედებს.

### 🧠 რა უნდა იცოდე შენ

- **აგენტი** ციკლია: მოდელი იღებს შეტყობინებას და ხელმისაწვდომი ფუნქციების (tools) სიას → წყვეტს, რომელი გამოიძახოს და რა არგუმენტებით → ჩვენი კოდი ასრულებს → შედეგი უბრუნდება მოდელს → მოდელი ან ისევ იძახებს ფუნქციას, ან პასუხს წერს. თავად მოდელი არაფერს „აკეთებს“.
- **RAG**: კითხვამდე ჩვენივე დოკუმენტებიდან ვპოულობთ შესაბამის ნაწყვეტებს და მოდელს ვაწვდით. მოდელი პასუხს მათზე დაყრდნობით წერს.
- **MCP** (Model Context Protocol) ღია სტანდარტია: tools და მონაცემი ერთხელ აღიწერება და სხვადასხვა AI კლიენტი იყენებს.
- .NET-ში: **Microsoft.Extensions.AI** (`IChatClient`, საერთო აბსტრაქცია) და **Microsoft Agent Framework** (აგენტები). დღეს მხოლოდ სახელები ახსენე.
- სილაბუსის ბლოკები: 1–3 საფუძვლები, 4–8 tools და ჩატი, 9–12 RAG, 13–18 აგენტები, 19–20 დაცვა, 21–24 შეფასება და საბოლოო პროექტი.

### 🗣️ როგორ ახსნა

1. დაიწყე კითხვით (🙋 ქვემოთ). ხშირად იტყვიან: „მოიგონა რაღაც“, „არ ახსოვდა“. დაიმახსოვრე: ორივეს დღეს ავხსნით (hallucination, stateless).
2. აჩვენე საბოლოო შედეგი — ჩატი და „აგენტი შიგნიდან“ (3). Injection-ის მაგალითზე ჰკითხე: „რატომ არ შეასრულა?“ და უპასუხე: „ამას ლექცია 19-ზე ისწავლით“.
3. „რა გაკლიათ?“ (4): ჯერ მათ ჰკითხე. API და ბაზა იციან. აკლიათ მოდელთან საუბარი, საკუთარი მონაცემის მიწოდება, მოქმედება, დაცვა და გაზომვა.
4. რეალური პროექტები (5): თითოზე თქვი, **რა ტექნიკაა** და **რომელ ლექციაზე** ისწავლიან.
5. დაასრულე მათი იდეით (8): 2 წუთი მეზობელთან ერთად მოიფიქრონ ერთი AI ფუნქცია საკუთარი პროექტისთვის. 2–3 იდეა მოისმინე.

### 🙋 კითხვა კლასს

**„სად გამოგიყენებიათ AI? რა გაგიკვირდათ — ან რა ვერ გააკეთა?“**
მოსალოდნელი პასუხები: ChatGPT კოდისთვის, თარგმანი, სურათები. „არასწორი რამ მითხრა“ → hallucination. „წინა საუბარი დაავიწყდა“ → context. ორივე დაფაზე ჩაწერე და ლექციის ბოლოს დაუბრუნდი.

### ⚠️ ტიპური არასწორი წარმოდგენები

- **„ამ კურსში AI-ს ვწვრთნით“** → არა. მზა მოდელს API-ით ვიძახებთ და სისტემად ვაქცევთ. წვრთნა სხვა პროფესიაა (ML Engineer).

- **„AI დამატებითი ფუნქციაა, backend კი ცალკე“** → AI სწორედ backend-ში ჩაშენდება: მონაცემი, უსაფრთხოება, ხარჯი, ტესტები.

## 2 · რატომ AI: სად მთავრდება if/else · 10 წთ · 11–15

### 📋 ლექციაზე

- ადამიანის ენა ზუსტი არ არის და წესებით ვერ დაიწერება
- LLM ენას „იგებს“, C# ზუსტად ასრულებს. მათ **ვაერთებთ**
- LLM = HTTP POST: `messages` შედის, ტექსტი და `usage` გამოდის
- 🙋 წყვილებში, 2 წთ: „დაწერეთ if/else ამ სამ შეტყობინებაზე“
- 💡 კალკულატორი vs ადამიანი

### 🎯 მთავარი სათქმელი

ადამიანის ენა ზუსტი არ არის და წესებით ვერ დაიწერება. LLM ენას „იგებს“, C# კი ზუსტად ასრულებს. ერთი მეორეს არ ცვლის: მათ **ვაერთებთ**.

### 🧠 რა უნდა იცოდე შენ

- **AI ⊃ ML ⊃ Deep Learning ⊃ GenAI ⊃ LLM.** ML: წესებს მონაცემიდან სწავლობს. DL: მრავალშრიანი ნეირონული ქსელით. GenAI: ახალ კონტენტს ქმნის. LLM: ტექსტის გენერაციის დიდი მოდელი (ტრანსფორმერი).
- LLM ორ ეტაპად იქმნება. **Pre-training**: უზარმაზარ ტექსტზე სწავლობს შემდეგი ტოკენის გამოცნობას. **Instruction tuning / RLHF**: ასწავლიან, რომ ინსტრუქციას მიჰყვეს და „ასისტენტივით“ უპასუხოს.

### 🧠 რა უნდა იცოდე შენ

- **Autoregressive** გენერაცია: ყოველი ახალი ტოკენი ითვლება მთელ წინა ტექსტზე (prompt + უკვე დაწერილი პასუხი). ამიტომ გრძელი პასუხი უფრო დიდხანს იწერება და output უფრო ძვირია.
- **Hallucination** არის ბუნებრივი შედეგი და არა ბაგი: მოდელი ოპტიმიზებულია დამაჯერებელ ტექსტზე. როცა ფაქტი არ იცის, ყველაზე სავარაუდო ფორმულირებას მაინც წერს.
